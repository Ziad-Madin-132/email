# 🎮 Gemgala 35 Accounts & OTP Management Dashboard
### لوحة إدارة وتفعيل حسابات Gemgala وجلب أكواد التحقق (OTP)

لوحة تحكم ويب تفاعلية حديثة وأداة برمجية لإدارة 35 حساب بريد إلكتروني نشط لتطبيق **Gemgala**، مع ميزة جلب أكواد التحقق (OTP) تلقائياً بنقرة زر واحدة أو مراقبتها لحظياً.

---

## ✨ المميزات الرئيسية (Features)

* **35 حساب نشط ومؤمن:** جميع الحسابات تم إنشاؤها وتأمينها بروابط مباشرة لصناديق الوارد.
* **جلب كود الـ OTP بضغطة زر واحدة:** فحص فوري لصندوق الوارد واستخراج كود التحقق بخط كبير مع زر نسخ بنقرة واحدة.
* **مراقبة تلقائية حية (Live Watch):** فحص مستمر كل 3 ثوانٍ لعرض الكود فور وصوله من Gemgala.
* **جدول تفاعلي كامل:** إمكانية البحث الفوري، ونسخ الإيميل أو كلمة المرور بنقرة واحدة، وزر مباشر لتسجيل الدخول في Mail.tm.
* **تصميم عصري (Dark Mode):** يدعم اللغة العربية بالكامل (RTL) ومتوافق مع جميع الشاشات والهواتف.
* **جاهز للرفع على GitHub و GitHub Pages:** يعمل في الوضعين (الوضع المحلي مع السيرفر + الوضع الثابت على GitHub Pages).

## 🚀 التشغيل السريع محلياً (Local Quick Start)

### الطريقة الأولى (الأسهل في ويندوز):
* اضغط نقرتين (Double-Click) على ملف `run_dashboard.bat`.
* سيفتح المتصفح تلقائياً على الرابط: `http://127.0.0.1:5000`.

### الطريقة الثانية (عبر سطر الأوامر):
```bash
python server.py
```
ثم افتح متصفحك على: `http://127.0.0.1:5000`

### فحص الكود من سطر الأوامر (CLI):
```bash
# فحص كود الحساب رقم 1
python check_inbox.py 1

# الانتظار والمراقبة المباشرة حتى يصل الكود للحساب رقم 5
python check_inbox.py 5 --watch

# فحص جميع الحسابات الـ 35
python check_inbox.py --all
```

## 🌐 خطوات الرفع على GitHub (Push to GitHub)

1. أنشئ مستودعاً جديداً (New Repository) على حسابك في GitHub (مثلاً باسم `gemgala-accounts-dashboard`).
2. افتح موجه الأوامر (CMD أو PowerShell) في مجلد المشروع ونفّذ الأوامر التالية:

```bash
# 1. تهيئة المستودع
git init

# 2. إضافة كافة الملفات
git add .

# 3. حفظ التغييرات
git commit -m "Initial commit: Gemgala 35 Accounts & OTP Dashboard"

# 4. تسمية الفرع الأساسي
git branch -M main

# 5. ربط المستودع بحسابك (استبدل الرابط برابط مستودعك)
git remote add origin https://github.com/YOUR_USERNAME/gemgala-accounts-dashboard.git

# 6. الرفع إلى GitHub
git push -u origin main
```

## 🌍 تفعيل الاستضافة المجانية على GitHub Pages

إذا أردت فتح الموقع مباشرة عبر رابط إنترنت (مثل `https://your-username.github.io/gemgala-accounts-dashboard/`):

1. ادخل على مستودعك على **GitHub**.
2. اذهب إلى **Settings** ⚙️ ثم اختر من القائمة الجانبية **Pages**.
3. تحت خيار **Build and deployment**، اختر:
   * **Source:** `Deploy from a branch`
   * **Branch:** `main` والمجلد `/ (root)`
4. اضغط على **Save**.
5. خلال دقيقة واحدة سيظهر لك الرابط المباشر للموقع.

> **ملاحظة بخصوص وضع GitHub Pages الثابت:**
> متصفح الإنترنت يمنع الاتصال المباشر بخوادم البريد الخارجية بسبب قيود (CORS).
> في نسخة GitHub Pages، يمكنك استعراض الـ 35 إيميل ونسخ البيانات بالكامل والبحث فيها، وهناك زر مباشر (Mail.tm ↗) بجانب كل حساب لتسجيل الدخول وقراءة الرسائل فوراً، بينما يوفر لك تشغيل `server.py` محلياً الجلب الآلي بنقرة واحدة داخل اللوحة.
